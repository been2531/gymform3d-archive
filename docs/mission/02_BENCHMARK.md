## Production grammar → reusable presets (principles, never copies)
- Hook: target muscle already lit within 0.3 s + one claim/question (≤7 words); ✗/✓ or A/B on screen at frame 0.
- Story: Hook (0–2 s) → wrong rep → right rep (same camera, same tempo) → one cue with measured angle → loop back.
- Camera: fixed A/B or split for comparison; one slow orbit or push-in for the "why"; close-up on the target muscle.
- Muscle highlight: only target muscles saturated; wrong = red/orange, right = green; glow follows muscle surface (needs true 3D or mask tracking).
- Anatomy layer transition: skin → muscle → bone as the "cut" (SynerMuscle, Anatomy Lab).
- Subtitles: one short line, big, safe zone; numbers only when measured.
- Edit rhythm: comparison reels 1 cut per 4–5 s (Demic); VO reels ~1 cut/s (M&M, Ethier). Our 4×5 s fits the comparison style.
- Length: best relative performers 12–16 s (SynerMuscle) and 30–39 s (Demic). Our 20 s is fine; 12–15 s loop variant worth an A/B.
- Rewatch: seamless loop (first = last frame), A/B sync, end on a question.
